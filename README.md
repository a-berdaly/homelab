# Homelab: DevSecOps learning project

Building, securing and automating a Linux server from scratch.
Hosts my personal portfolio website.

## Goals
- Learn Linux system administration and DevOps hands-on
- Security built into every step (DevSecOps)
- Everything documented and reproducible

## Roadmap
- [x] Stage 1-3: Linux basics, users & permissions, systemd & logs
- [ ] Stage 4: Git, networking, disks (LVM), firewall
- [ ] Stage 5: Bash automation (backups, healthcheck + Telegram alerts)
- [ ] Stage 6: Nginx, HTTPS, fail2ban, hardening, lynis audit
- [ ] Stage 7: Docker, Ansible, GitHub Actions CI/CD, monitoring

## Environment
- Ubuntu Server 26.04 LTS (VMware)
